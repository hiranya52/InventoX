# 🛒 ShopManage - Dynamic Product Inventory Dashboard

ShopManage is a **Single Page Application (SPA)** that lets admins **view, add, update, and delete products** easily using a mock API. 💻✨

---

## 📋 Features

- 🌐 **Responsive Navbar** with the logo "ShopManage" & an "Add Product" button  
- 🛍️ **Product Grid/Table** showing:  
  - 🖼️ Product Image  
  - 🏷️ Title & 💲 Price  
  - 📂 Category  
  - ✏️ Edit & 🗑️ Delete Buttons  
- 📝 **Modal Form** for Adding & Editing products  
- 🔄 **CRUD Operations** with async JS:  
  - ➕ Create (POST)  
  - 👀 Read (GET)  
  - ✏️ Update (PUT)  
  - 🗑️ Delete (DELETE)  
- ⏳ **Loading Spinner** while fetching data  
- ⚠️ **Error Handling** for network/API issues  

---

## 🛠️ Technical Stack

- **Structure:** HTML5  
- **Styling:** Tailwind CSS (or Bootstrap 5)  
- **Logic:** Vanilla JavaScript  
- **Data Source:** [DummyJSON API](https://dummyjson.com/products)
